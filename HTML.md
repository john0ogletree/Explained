# HTML Explained

**HTML** (HyperText Markup Language) is the foundational standard markup language used to create and structure documents on the web. It tells web browsers how to display text, links, images, and other multimedia elements on a page.

---

## 1. The Core Anatomy of an HTML Document

Every modern HTML document follows a standard structural blueprint. It begins with a document type declaration, followed by the root `<html>` element containing the head metadata and the visible body content.

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document Title</title>
</head>
<body>
    <h1>Hello, World!</h1>
    <p>This is a paragraph rendered inside the browser.</p>
</body>
</html>
